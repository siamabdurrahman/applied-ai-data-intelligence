## Portfolio purpose

These notebooks document the progression from data exploration and preprocessing to model evaluation and interpretation during the AI for Data Intelligence module at Canterbury Christ Church University. The collection demonstrates practical implementation and reflective experimentation rather than a single production application.

## Reproducing the notebooks

```bash
git clone https://github.com/siamabdurrahman/applied-ai-data-intelligence.git
cd applied-ai-data-intelligence
python -m venv .venv
```

Activate the environment, then install the declared dependencies:

```bash
pip install -r requirements.txt
jupyter notebook
```

Some notebooks require external datasets or optional packages referenced within their cells. Review the notebook configuration and replace historical local paths before execution.

## Scope and responsible use

This repository contains coursework and learning artefacts. Results are not presented as externally validated research estimates, and the healthcare examples are not clinically validated or suitable for diagnosis, treatment or patient-care decisions. Dataset licences and usage conditions should be checked at the original source before reuse.
